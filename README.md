# Canyon Frontend

This is the frontend application for the Canyon project. It is built with Next.js (App Router), React, and Tailwind CSS. The project uses Bun as the primary package manager and runtime.

## Tech Stack

- **Framework**: Next.js (App Router)
- **Library**: React
- **Styling**: Tailwind CSS
- **UI Components**: Radix UI Primitives & custom components
- **Form Handling**: React Hook Form & Zod
- **Icons**: Lucide React
- **Package Manager & Runtime**: Bun

## Getting Started

### Prerequisites

- [Bun](https://bun.sh/) installed on your system.

### Setup

1. Install dependencies:
   ```bash
   bun install
   ```

### Development

Run the development server using Bun:
```bash
bun run dev
```
Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

### Build and Production

To build the project for production:
```bash
bun run build
```

To start the production server:
```bash
bun run start
```

### Linting

To check for linting errors:
```bash
bun run lint
```
